# Jharkhand Civic Connect

Build a minimalistic, functional civic problem-solving platform for Jharkhand called “Jharkhand Civic Connect.” Implement the complete role-based demo flow specified by the user: Citizen/NGO issue reporting through Panchayat verification, AI Problem Statement generation only after verification, University solution progression, Industry support/milestones, and Government/Admin oversight. Use realistic Jharkhand locations and issue data, including the Dumka handpump example through to impact. Deliver a responsive, accessible civic/government/research visual system and functional mock-state prototype with navigation, role switching, submissions/uploads/location, verification outcomes, AI PS review, university team/mentor/progress flows, pledges/milestones, notifications, filters/search/maps/analytics. Protect citizen privacy in role views. Use the user’s stated institutional low-saturation blue/green design rules and avoid flashy SaaS patterns.
